# Building the documentation

Use Python 3.10 through 3.13 and run these commands from the repository root:

```bash
python -m pip install -e ".[docs]"
python -m sphinx -W -b html -D nb_execution_mode=off docs docs/_build/html
```

Open `docs/_build/html/index.html` to view the result. The build treats Sphinx
warnings as errors. Current guides and API reference pages describe the
unreleased 3.0 API. Historical 2.x notebooks and teaching material are stored in
[history](history/README.md) and excluded from the build.

The documentation dependencies include Sphinx and the configured theme. Reinstall
the `docs` extra if either is missing. A LaTeX installation is additionally
required to compile PDF output generated by `python -m sphinx -b latex docs docs/_build/latex`.
