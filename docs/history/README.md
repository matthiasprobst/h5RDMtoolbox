# Archived documentation

These files are historical references and are excluded from the current Sphinx
build. They may require APIs or dependencies removed in 3.0. Use the v2.9.0 Git
tag to reproduce the original software environment; see the current
[migration guide](../migration-3.md) when adapting an existing workflow.
